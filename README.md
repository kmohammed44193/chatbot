# Django + ChatterBot terminal chatbot

Includes both Python code files (`chatbot.py` and `chatbot_project/settings.py`), the required Python package initializer, and a dependency manifest.

## Run

1. Create a virtual environment: `python -m venv venv`
2. Activate it on Windows: `venv\Scripts\activate`
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `python chatbot.py`
5. Type `exit` to quit.

Compatibility note: ChatterBot dependency support varies by Python version. Use a compatible Python version and consult ChatterBot documentation if installation fails. The code has been syntax checked, not executed with installed dependencies.
